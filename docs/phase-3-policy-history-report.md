# Recorded policy decisions and historical replay checkpoint

27 October 2026. Phase 3D implementation in progress; full acceptance remains pending.

Additive schema 17 stores immutable, content-hashed trusted policy configuration capsules and evaluation-to-capsule bindings. A capsule records configured operational rules, scope, source-verification allowlist and the existing AICTE reference register. Capture is a record of application configuration, not issuer confirmation. Existing evaluations are never backfilled with a fabricated original configuration. Frozen schemas 13/14/15 remain unchanged and migrate forward.

New evaluations preserve their policy configuration, institution/instrument facts, reviewed proofs and immutable source references. Rule explanations include policy/version/source/effective period, applicability predicates, expected/actual values, evidence and proof references, exceptions, missing evidence, review requirements and next actions. Reference AICTE checks retain academic-year applicability and explicitly unknown exact dates. Their mirrored/unconfirmed authority remains provisional. Synthetic tests remain fictional; unsupported/unavailable sources require review. No score or automatic final approval is introduced.

Authorized case users can inspect current and historical policy explanations, with signed scoped pagination over evaluation history. Source metadata includes exact document UUID/version/hash and extracted field page/box/method/raw value/confidence where available. The protected viewer can select the extraction recorded with a particular evaluation rather than silently showing a later correction. Other extraction identities/documents and cross-case access are rejected. Raw technical references are expandable; the main rule explanation uses plain language.

Replay defaults to the recorded capsule for frozen evaluations. An explicit current-configuration reassessment can apply new trusted rules to the same frozen facts. Current-facts replay refreshes stale current evidence first and then runs a policy-only replay; it does not backdate a financial assessment. Existing evidence/evaluations and their prior outcomes are unchanged. Legacy facts without a captured configuration are explicitly marked as a current-configuration reassessment with missing original configuration.
