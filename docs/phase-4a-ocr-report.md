E.g. a reference included the following deposit amount; bank included the following IFSC; institution included the depositor. This justifies field segmentation against actual recognized labels/word boxes, rather than changing recognition to match truth. Resource measurements use a benchmark-only wrapper around the real worker with secret-minimized environment and unchanged recognition. CPU is process delta; cold latency includes worker startup; warm jobs reuse at most 25 documents per worker. OS filesystem cache is uncontrolled. The 384 MiB argument limits V8 old space, not total native/WASM/RSS; measured peak RSS is reported separately and can exceed that value. No production SLA or calibrated confidence is claimed.
