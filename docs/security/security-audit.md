## Evidence and residual risks

Run npm run verify for the full suite. Raw current output: ../evaluation/phase-1-2-tests.txt. Browser log: ../evaluation/final-gap/browser.txt. Results and exact counts: ../evaluation/results.md.

No current passing test proves every authorization branch or file-parser vulnerability safe. Two roles are supported; missing administrator/supervisor/audit-reviewer roles are original Phase 1 functionality gaps. API history/list queries remain unpaginated and may consume large memory. Node SQLite is experimental and this service has one owner process. Request throttles are per process/IP; inherited filesystem ACLs and local HTTP are deployment constraints.

Audit triggers are application-level append-only protection. A database/filesystem administrator can remove triggers or alter files; no cryptographic chain or independent checkpoint exists. No MFA/recovery UI, malware service, OS sandbox, production TLS termination, encrypted storage/key management, managed backup/restore service, full correlated request logging, broad browser matrix or complete ASVS review is implemented. Preserve local-only synthetic operation until these are resolved. No production financial confirmation or regulatory authority is granted.
